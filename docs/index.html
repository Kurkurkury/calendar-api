OpenClaw Calendar

OpenClaw Calendar ist eine persönliche Integration für Google Kalender. Sie unterstützt den autorisierten Nutzer dabei, Kalender einzusehen und ausdrücklich angeforderte Terminänderungen auszuführen.

  • Kein öffentlicher Kalenderdienst und keine Werbung
  • Zugriff nur nach Google-OAuth-Zustimmung
  • Keine Weitergabe oder kein Verkauf von Kalenderdaten zu Werbezwecken
